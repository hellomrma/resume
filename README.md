# Portfolio Website - 마광습 (Gwang Seub Ma)

Frontend Developer 마광습의 포트폴리오 웹사이트입니다.

## 📋 프로젝트 소개

경력 14년 이상의 Frontend Developer 마광습의 포트폴리오 웹사이트입니다. HTML, CSS, JavaScript 기반으로 제작되었으며, React, Next.js, Vue.js, TypeScript 등 최신 프론트엔드 기술을 활용합니다. AI 코딩 도구를 활용해 설계부터 구현, 문서화까지 진행하는 작업 방식과 꾸준한 개인 프로젝트, 리포트·제안서 작성 역량도 함께 소개합니다. 반응형 디자인과 SEO 최적화가 적용되어 있습니다.

## 🛠 기술 스택

- **HTML5** - Semantic HTML, Web Standards
- **CSS3** - Flexbox, Grid, Responsive Design, SCSS
- **JavaScript** - ES6+, Vanilla JavaScript
- **Frontend Framework / Library** - React, Next.js, Vue.js, TypeScript

## 📁 프로젝트 구조

```
resume/
├── index.html          # 메인 HTML 파일
```

## 🎨 주요 기능

- **반응형 디자인**: 모바일, 태블릿, 데스크톱 최적화
- **SEO 최적화**: 메타 태그, Open Graph, Twitter Card, 구조화된 데이터 (JSON-LD)
- **접근성**: ARIA 속성, 시맨틱 HTML
- **블랙/그레이/화이트 테마**: 모던하고 깔끔한 디자인

## 🚀 실행 방법

1. 저장소 클론
```bash
git clone https://github.com/hellomrma/resume.git
cd resume
```

2. 웹 서버 실행 (예: Python)
```bash
# Python 3
python -m http.server 8000

# 또는 Node.js (http-server)
npx http-server
```

3. 브라우저에서 접속
```
http://localhost:8000
```
